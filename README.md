# Hitiktok Landing

Landing page simple creada con React + Tailwind, lista para desplegar en GitHub Pages.

Pasos rápidos (PowerShell):

```powershell
# 1) Instalar dependencias
npm install

# 2) Ejecutar en desarrollo
npm start

# 3) Compilar para producción
npm run build

# 4) (Opcional) Desplegar a GitHub Pages
# - Actualiza el campo "homepage" en package.json con tu URL: https://<TU_USUARIO>.github.io/hitiktok-app
npm run deploy
```

Notas:
- Reemplaza el `src/App.js` con tu nombre real y enlaces a redes.
- Si ya tienes un proyecto existente, integra los archivos de Tailwind (`tailwind.config.cjs`, `postcss.config.cjs`) y añade las dependencias listadas.
